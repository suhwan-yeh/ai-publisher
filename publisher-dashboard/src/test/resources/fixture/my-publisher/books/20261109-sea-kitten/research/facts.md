## 1. 고양이 습성

### 1-1 수염
- 수염은 일반 털보다 굵고 뿌리가 깊으며 신경·근육과 이어져 있다. 
  - 출처: 데일리벳 "고양이 전문가가 말하는 고양이의 촉각" https://www.dailyvet.co.kr/?p=208939 (수의 전문 매체) / 확인 2026-11-09
  - 안전한 문장: "고양이 수염은 보통 털보다 굵고 뿌리가 깊어서, 주변을 느끼는 안테나 같아요." ✅
- 수염이 균형을 잡아 준다는 설명은 한 출처의 설명일 뿐이다. 다른 출처는 귀 속 액체(평형기관)의 움직임이 균형을 결정한다고 한다.
  - 출처: 위 데일리벳 및 검색 결과 간 불일치 / 확인 2026-11-09 ⚠️
  - 안전한 문장: "수염으로 좁은 곳과 바람을 느껴요." (수염=균형 단정 금지. 균형은 "귀 속에도 균형 잡는 곳이 있대요" 정도)

### 1-2 물을 싫어하는 이유
- 집고양이의 조상은 아프리카 야생고양이로, 물이 드문 건조한 곳에서 살았다는 설명이 많다.
  - 출처: Eni Scuola "Why do cats (almost always) hate water?" https://eniscuola.eni.com/en-IT/news/2025/why-do-cats-almost-always-hate-water.html / 확인 2026-11-09 ⚠️(교육 매체, 이 주제의 직접 연구는 적음)
- 털이 젖으면 무거워지고 체온을 잃기 쉽다. 고양이는 헤엄칠 수 있고 뜰 수도 있다. 일부 품종(터키시 밴 등)은 물을 즐기기도 한다.
  - 출처: 같은 Eni Scuola 글, Inverse https://www.inverse.com/science/why-do-cats-hate-water-evolution / 확인 2026-11-09 ⚠️
- 털의 방수 여부는 출처마다 말이 다르다 → "방수 털"이라고 쓰지 말 것.
  - 안전한 문장: "고양이는 대체로 젖는 걸 싫어해요. 털이 젖으면 무겁고 추워지거든요. 그래도 헤엄칠 수는 있대요." ✅
  - 주의: 헤엄칠 수 있다고 해서 바다에 빠져도 안전하다는 인상은 주지 않기(아이 독자). 이야기에서는 배 안·구명조끼·어른 도움 등으로 처리 권장.

### 1-3 낮잠
- 어른 고양이는 하루 12~16시간 잔다는 설명이 가장 흔하다. 새끼는 더 많이 자고(약 18시간, 최대 20시간이라는 자료도 있음), 한 번에 길게보다 여러 번 짧게 나눠 잔다.
  - 출처: 데일리벳 https://www.dailyvet.co.kr/?p=66695 , PetMD https://www.petmd.com/cat/behavior/why-do-cats-sleep-so-much / 확인 2026-11-09 ⚠️(수의사 감수 매체, 학술기관 아님)
  - 안전한 문장: "아기 고양이는 하루의 대부분을 쿨쿨 자요. 짧게 자고 일어나고, 또 자고요." ✅ (정확한 시간 숫자는 쓰지 않기)

### 1-4 균형·떨어질 때 (추가 확인 필요)
- "고양이는 높은 데서 떨어져도 발로 착지한다"는 흔한 말은 이번에 공공 출처로 확인하지 못함. (확인 필요) → 쓰지 않거나 "몸을 잘 돌려요" 수준만.

### 1-5 멀미 (민준 요청 추가, 확인 2026-11-09)
- 고양이도 이동 중 크게 울고, 침을 흘리고, 토할 듯 불안해할 수 있다. 반복되면 수의사와 상담. 숨쉬기 힘들어하거나 쓰러지면 바로 진료가 필요하다.
  - 출처: miso.kr 블로그 https://miso.kr/blog/thread/%EA%B3%A0%EC%96%91%EC%9D%B4-%EC%9E%A5%EA%B1%B0%EB%A6%AC-%EC%9D%B4%EB%8F%99-%EA%BF%80%ED%8C%81 ⚠️⚠️(블로그, 참고만. 수의사 자료 미확보)
  - "배 멀미"를 직접 다룬 자료는 못 찾음 (확인 필요).
  - 안전한 문장: "아기 고양이도 흔들리는 길에서는 속이 울렁거릴 수 있어요." (과학적 단정·병명 쓰지 않기)

### 1-6 야행성? 
- 고양이는 완전한 야행성보다 해질녘·새벽에 가장 활발한 "박명성"이라는 설명이 수의사 인용 자료에 많다. 조상이 사막 출신이라 뜨거운 낮을 피한다는 설명도 있다.
  - 출처: Wisconsin Humane Society "alarm clock cats" https://www.wihumane.org/resource/alarm-clock-cats/ ; Embrace "Are cats nocturnal or crepuscular" https://www.embracepetinsurance.com/waterbowl/article/are-cats-nocturnal-or-crepuscular / 확인 2026-11-09 ⚠️
  - 안전한 문장: "고양이는 해 질 녘과 새벽에 눈이 반짝 깨어나요." ✅ ("밤새 돌아다닌다"는 쓰지 않기)

### 1-7 항구

## 2. 배와 고양이
- 고양이는 오래전부터 배에서 쥐를 막는 일을 해 왔다. 고대 이집트 벽화, 페니키아인, 바이킹 이야기가 소개되고, 범선 시대에는 쥐가 식량·돛을 갉아서 더 필요했다. 지금도 일부 선원은 배에 고양이를 둔다.
  - 출처: Professional Mariner "No kitten: Time again to welcome cats aboard merchant ships" https://professionalmariner.com/no-kitten-time-again-to-welcome-cats-aboard-merchant-ships/ ; Snopes https://www.snopes.com/news/2023/10/12/naval-cat-passports/ / 확인 2026-11-09 ⚠️(언론 매체, 고대 기원 세부는 학술 확인 필요)
  - 안전한 문장: "아주 오래전부터 배에는 쥐를 쫓아 주는 고양이가 살았대요." ✅ ("이집트 때부터" 같은 단정은 (확인 필요))

## 3. 바다 동물
### 3-1 갈매기
- 괭이갈매기는 우리 바다에서 흔히 보이는 갈매기이며, 멸치 같은 물고기 떼를 먹는다. 갈매기 떼가 바다 위에 모여 내리꽂히는 곳 아래에 물고기 떼가 있다는 어민들의 경험담이 있다.
  - 출처: 뉴스토마토 "(생명의 숨소리) 대한민국 해상 파수꾼 괭이갈매기" https://newstomato.com/ReadNews.aspx?no=1311510 (해양생물 관련 기관 연재 기사) / 확인 2026-11-09 ⚠️
  - 안전한 문장: "갈매기들이 바다 위에 모여 있으면 그 아래에 물고기 떼가 있다고, 뱃사람들은 말해요." ✅
- 갈매기의 일반 습성(이동 등)은 공공 출처 미확보. (확인 필요)

### 3-2 고래
- 상괭이는 몸길이 1.5~1.9m 정도의 아주 작은 고래로, 우리 바다에 살며 "웃는 고래"로 불린다. 어민들 말로는 갈매기가 많이 모이거나 낮게 나는 곳에 상괭이가 있다 (기사는 이를 과학적 사실이라 설명).
  - 출처: 뉴스토마토 "(생명의 숨소리)'웃는 고래' 상괭이" https://newstomato.com/ReadNews.aspx?no=1307675 / 확인 2026-11-09 ⚠️
  - 안전한 문장: "우리 바다에는 웃는 얼굴 같은 작은 고래, 상괭이가 살아요." ✅
- 고래가 폐로 숨 쉬고 숨구멍으로 물(숨)을 뿜는 원리는 이번 조사에서 공식 출처를 못 찾음. (확인 필요) → 필요하면 국립수산과학원 고래연구소 자료 재조사. "고래가 숨을 쉬러 올라와요" 수준은 널리 알려진 상식이나 출처 미확보.
- 좌초된 고래를 보면 119나 해양경찰서에 알린다는 안내가 있음 (국립수산과학원 고래연구센터 언급). 출처: 비건뉴스 https://www.vegannews.co.kr/news/article.html?no=391025 ⚠️ — 동화에서 아이가 고래를 만져 도우려 하지 않게 "어른에게 알리기" 정도로 활용 가능.

### 3-3 파도
- 파도의 원리(바람 등)는 이번 조사에서 공식 출처 미확보. (확인 필요) → 동화에서는 "바람이 불면 파도가 커져요" 정도 의인화 표현 권장, 과학 설명 금지.

## 4. 별자리 길잡이
- 북극성은 북반구에서 항상 거의 북쪽에 있어 방향을 알려 준다. 밝은 별은 아니다(밝기 약 48번째).
  - 출처: Star Walk "[별 이야기] 북극성은 항상 북쪽입니까?" https://starwalk.space/ko/news/polaris-north-star / 확인 2026-11-09 ⚠️(천문 교육 매체)
- 북두칠성 국자 머리 바깥쪽 두 별(두베·메락)을 이어 늘이면 북극성이 나온다. 북극성은 작은곰자리 꼬리 끝에 있다.
  - 출처: Star Walk 큰곰자리 https://starwalk.space/ko/news/ursa-major-constellation-guide ; EarthSky https://earthsky.org/?p=2964 / 확인 2026-11-09 ⚠️
  - 안전한 문장: "국자 모양 별 일곱 개의 끝 두 별을 쭉 이으면 북쪽을 알려 주는 별이 나와요." ✅
- 카시오페이아(W자)가 북쪽 하늘 길잡이 별자리이고 북극성 반대편에 있다는 설명은 일반 지식으로 검색에서 직접 확인 못함. (확인 필요)
- 주의: 한국에서 북극성의 높이는 위도와 같아 지평선 위 약 33~38도 정도(위도 일반 원리는 Star Walk가 설명, 한국 수치는 (확인 필요)). 숫자는 쓰지 말 것.
- 이야기 주의: 도시 불빛·구름이 있으면 북극성은 잘 안 보인다(밝지 않기 때문). 맑은 밤 장면에 쓰기 좋음.

## 6. 동화에 쓸 때의 한 줄 정리
1. 고양이는 물을 싫어하는 편 → 이야기의 용기 포인트로 좋음 (안전 문장 있음)
2. 수염=안테나 느낌 OK, "수염이 균형" 단정은 피하기
3. 낮잠 많음 OK, 시간 숫자 빼기
4. 배에는 예부터 고양이가 살았다 OK
5. 갈매기 떼 아래엔 물고기 떼 (뱃사람 말) OK
6. 북두칠성 → 북극성 길잡이 OK, 숫자 빼기
