## 1. Spring MVC (요청과 응답)

| 용어 | 뜻 | 예시 | 나오는 파일 |
|---|---|---|---|
| `@Controller` | 화면 요청을 받는 클래스라고 알립니다. 메서드가 돌려주는 글자는 **템플릿 이름**입니다. | `return "index";` → `templates/index.html` | `controller/*.java` |
| `@RestController` | JSON을 돌려주는 클래스라고 알립니다. 메서드가 돌려주는 객체를 Jackson이 JSON으로 바꿉니다. | `return new ChatPollResponse(…)` → `{"online":true,…}` | `api/*.java` |
| `@RequestMapping` | 클래스 안 모든 메서드 주소의 앞부분을 정합니다. | `@RequestMapping("/api/chat")` | `api/ChatApiController.java` |
| `@GetMapping` / `@PostMapping` | GET·POST 방식으로 온 그 주소의 요청을 이 메서드가 받습니다. | `@GetMapping("/books/{id}")` | `controller/*`, `api/*` |
| `@PathVariable` | 주소 안의 `{이름}` 부분을 꺼내 매개변수에 넣습니다. 자료형도 바꿔 줍니다. | `GET /books/3` → `Long id = 3` | `DashboardController.book()` |
| `@RequestParam` | 폼 값이나 `?이름=값`을 꺼냅니다. `defaultValue`로 없을 때의 값을 정합니다. | `POST /order` 몸통 `text=…` → `String text` | `ChatPageController.order()` |
| `@RequestBody` | 요청 몸통의 JSON을 자바 객체로 바꿉니다. | `{"text":"좋아요"}` → `SendMessageRequest` | `ChatApiController.send()` |
| `Model` | 컨트롤러가 템플릿에 넘길 값을 담습니다. | `model.addAttribute("books", …)` → 템플릿 `${books}` | `controller/*` |
| `redirect:` | 템플릿 이름이 아니라 "다른 주소로 다시 요청하라"는 302 응답을 만듭니다. | `return "redirect:/chat";` → `302 Location: /chat` | `ChatPageController`, `DashboardController` |
| PRG (Post → Redirect → Get) | 폼을 POST로 받은 뒤 302로 다른 주소를 GET하게 합니다. 새로고침해도 POST가 다시 가지 않습니다. | `POST /order` → `302` → `GET /chat` | 흐름 C |
| `RedirectAttributes` (flash) | redirect한 다음 요청에서 한 번만 꺼낼 값을 담습니다. | `ra.addFlashAttribute("error", …)` | `ChatPageController.order()` |
| `ResponseEntity` | 상태코드·헤더·몸통을 직접 정한 응답입니다. | `ResponseEntity.created(uri).body(dto)` → 201 + Location | `ChatApiController.send()` |
| `@ResponseStatus` | 예외나 메서드에 응답 상태코드를 붙입니다. | `@ResponseStatus(HttpStatus.NOT_FOUND)` | `service/NotFoundException.java` |
| `FileSystemResource` | 디스크의 파일을 응답 몸통으로 보냅니다. | `new FileSystemResource(path)` | `controller/FileResponses.java` |
| DTO | 요청·응답의 모양만 담은 클래스입니다. 엔티티를 그대로 내보내지 않고 필요한 값만 담습니다. | `ChatMessageResponse` | `dto/*.java` |
| 정적 팩토리 메서드 `from()` | 다른 객체를 받아 새 객체를 만들어 돌려주는 static 메서드입니다. | `ChatMessageResponse.from(엔티티)` | `dto/*.java` |
| 엔티티와 DTO의 구분 | 엔티티 = DB 표의 행, DTO = 화면·API에 보낼 모양. 엔티티의 `uniqueKey` 같은 값은 DTO에 넣지 않습니다. | `ChatMessage` ↔ `ChatMessageResponse` | `domain/`, `dto/` |

## 2. 스프링이 객체를 만들고 넣어 주기

| 용어 | 뜻 | 예시 | 나오는 파일 |
|---|---|---|---|
| 빈(Bean) | 스프링이 만들어 관리하는 객체입니다. | `ChatService` 객체 하나 | 전체 |
| `@Component` | 이 클래스로 빈을 만들라고 알립니다. `@Component("fmt")`처럼 이름을 줄 수 있습니다. | `@Component("fmt") ViewHelpers` → 템플릿 `${@fmt.time(…)}` | `client/*`, `scan/*`, `ViewHelpers` |
| `@Service` | `@Component`와 같은 기능입니다. 업무 규칙을 맡은 클래스에 씁니다. | `@Service ChatService` | `service/*` |
| 생성자 주입 | 생성자의 매개변수로 필요한 빈을 받습니다. 스프링이 알아서 넣어 줍니다. `new`로 직접 만들지 않습니다. | `public ChatApiController(ChatService chatService)` | 전체 |
| `@Autowired` | 필드에 빈을 넣어 줍니다. 이 프로젝트는 시험 클래스에서만 씁니다. | `@Autowired TestRestTemplate http;` | `src/test/**` |
| `@Configuration` / `@Bean` | 설정 클래스 / 이 메서드가 돌려주는 객체를 빈으로 등록합니다. | `@Bean SecurityFilterChain …` | `config/SecurityConfig.java` |
| `@Value` | `application.yml`의 값 하나를 매개변수에 넣습니다. `:` 뒤는 기본값입니다. | `@Value("${publisher.bridge-url:http://127.0.0.1:8787}")` | `client/FakechatClient.java` |
| `@ConfigurationProperties` | `publisher.*` 같은 설정 묶음을 한 객체로 읽습니다. | `PublisherProperties.rootPath()` → `/root/my-publisher` | `config/PublisherProperties.java` |
| `@EnableConfigurationProperties` | 위 설정 객체를 쓰겠다고 알립니다. | `PublisherDashboardApplication` | `PublisherDashboardApplication.java` |
| `@SpringBootApplication` | 프로그램의 시작 클래스입니다. 이 패키지 아래의 `@Component`들을 찾아 빈으로 만듭니다. | `main()` → `SpringApplication.run(…)` | `PublisherDashboardApplication.java` |
| `@PostConstruct` | 빈을 만든 직후 한 번 실행할 메서드입니다. | 직원 명부 처음 읽기 | `config/StaffDirectory.java` |
| `@EnableScheduling` / `@Scheduled` | 시각에 맞춰 메서드를 부르는 기능을 켭니다 / 그 메서드와 간격을 정합니다. | `@Scheduled(fixedDelayString = "${publisher.scan-interval-ms:10000}")` | `scan/ScanScheduler.java` |
| `@EventListener`, `ApplicationReadyEvent` | 사건이 일어나면 메서드를 부릅니다. `ApplicationReadyEvent` = 시작이 모두 끝났다는 사건입니다. | `first()` → "관리 화면 준비 완료: 책 5권, 기록 383건 읽음" | `scan/ScanScheduler.java` |
| `@Transactional` | 메서드 안의 DB 작업을 하나로 묶습니다. 끝까지 성공하면 반영, 예외면 모두 되돌립니다. `readOnly = true`는 읽기만 합니다. | `ChatService.send()` | `service/*`, `scan/*` |
| 프로필(profile) | 설정 묶음의 이름입니다. `--spring.profiles.active=prod`로 켜면 `application-prod.yml`이 덧씌워집니다. | 서버 실행 명령 | `application-prod.yml` |

## 3. JPA와 DB

| 용어 | 뜻 | 예시 | 나오는 파일 |
|---|---|---|---|
| JPA / Hibernate | 자바 객체와 DB 표의 행을 서로 바꾸는 기술 / 그 구현입니다. SQL을 대신 만들어 실행합니다. | `save(객체)` → `insert into …` | `domain/`, `repository/` |
| `@Entity`, `@Table` | 이 클래스가 DB 표와 대응한다고 알립니다 / 표 이름과 고유 조건(`uniqueConstraints`)을 정합니다. | `@Table(name = "book_order")` | `domain/*.java` |
| `@Id`, `@GeneratedValue(IDENTITY)` | 기본 키 / 번호는 DB가 정합니다. insert의 id 자리에 `default`가 들어갑니다. | `insert into book_order (at,chat_key,text,id) values (?,?,?,default)` | `domain/*.java` |
| `@Column` | 열의 이름·길이·`unique`·`nullable`을 정합니다. | `@Column(unique = true) chatKey` | `domain/*.java` |
| `@Lob` | 긴 글 열입니다. H2는 `clob`, MySQL은 `longtext`입니다. | `@Lob private String text;` | `domain/*.java` |
| `@Enumerated(STRING)` | enum 값을 이름 글자로 저장합니다. | `stage = 'DONE'` | `domain/Book.java` |
| `@OneToMany` / `@ManyToOne` | 한 행이 여러 행을 가짐 / 여러 행이 한 행을 가리킴. | `Book` 1 ↔ N `BookFile` (`book_id`) | `domain/Book.java`, `BookFile.java` |
| `@OrderBy` | 목록을 읽을 때의 정렬입니다. | `order by f1_0.kind` | `domain/Book.java` |
| `protected` 기본 생성자 | JPA가 select 결과로 객체를 만들 때 씁니다. 우리 코드에서는 쓰지 않도록 protected로 둡니다. | `protected BookOrder() {}` | `domain/*.java` |
| `JpaRepository<엔티티, 키 자료형>` | 이 인터페이스를 이어받기만 하면 `save`, `findById`, `findAll`, `count`가 생깁니다. 구현 클래스는 Spring Data가 만듭니다. | `interface ChatMessageRepository extends JpaRepository<ChatMessage, Long>` | `repository/*.java` |
| 메서드 이름 쿼리 | 메서드 이름 규칙(`findBy…`, `existsBy…`, `OrderBy…`, `Top5`)으로 SQL을 만듭니다. | `existsByUniqueKey(k)` → `select cm1_0.id from chat_message cm1_0 where cm1_0.unique_key=? fetch first ? rows only` | `repository/*.java` |
| `ddl-auto` | 시작할 때 표를 어떻게 할지 정합니다. `update` = 없는 표·열을 만듭니다(내 PC), `validate` = 확인만 합니다(서버). | `application.yml`, `application-prod.yml` | 설정 |
| H2 | 자바로 만든 작은 DB입니다. 파일 하나에 저장하고 설치가 필요 없습니다. `jdbc:h2:mem:`은 메모리 DB입니다. | `~/.publisher-dashboard/db.mv.db` | `application.yml`, 시험 |
| Flyway | `db/migration/V1__설명.sql` 같은 SQL 파일을 번호 순서대로 한 번씩 실행하고 `flyway_schema_history` 표에 기록합니다. **이미 실행한 파일은 주석 한 글자도 바꾸면 안 됩니다**(검사값 checksum이 달라져 시작이 멈춥니다). | `V1__init.sql` | [DB 표 설명](DB-표-설명.md) |
| `utf8mb4` | 한글과 이모지(📘)까지 저장할 수 있는 MySQL 글자 방식입니다. | `default charset=utf8mb4` | `V1__init.sql` |
| `JdbcTemplate` | SQL 글자를 직접 실행하는 스프링 도구입니다. | `select count(*) from flyway_schema_history …` | `MySqlMigrationTest` |

## 4. 검사(Validation)와 오류

| 용어 | 뜻 | 예시 | 나오는 파일 |
|---|---|---|---|
| `@Valid` | `@RequestBody`로 만든 객체의 검사 규칙을 실행하라고 알립니다. 실패하면 메서드 본문이 실행되지 않습니다. | `send(@Valid @RequestBody SendMessageRequest request)` | `ChatApiController` |
| `@NotBlank`, `@Size` | 빈 글·공백만 있는 글 금지 / 길이 제한입니다. `message`가 오류 문장이 됩니다. | `{"text":"  "}` → `"보낼 말을 적어 주세요."` | `dto/SendMessageRequest.java` |
| Bean Validation | `@NotBlank` 같은 검사 규칙의 표준입니다. `spring-boot-starter-validation`이 실행합니다. | | `build.gradle` |
| `@RestControllerAdvice` | 모든 `@RestController`에서 생긴 예외를 한곳에서 받습니다. | `ApiExceptionHandler` | `api/ApiExceptionHandler.java` |
| `@ExceptionHandler` | 어떤 예외를 이 메서드가 처리할지 정합니다. | `@ExceptionHandler(NotFoundException.class)` → 404 | `api/ApiExceptionHandler.java` |
| 예외(Exception), `throw` | 정상으로 이어갈 수 없을 때 만드는 객체 / 그 객체를 던져 메서드를 멈춥니다. 위쪽의 `catch`나 `@ExceptionHandler`가 받습니다. | `throw new NotFoundException("책을 찾을 수 없어요.")` | `service/*` |
| `RuntimeException`, `extends` | `throws`를 적지 않아도 되는 예외 / 다른 클래스를 이어받습니다. | `class NotFoundException extends RuntimeException` | `service/*Exception.java` |
| `try-catch`, multi-catch | 예외를 잡아 처리합니다 / 두 종류를 한 번에 잡습니다. | `catch (IllegalArgumentException \| ChannelUnavailableException e)` | `ChatPageController.order()` |
| `try-with-resources` | `try (…)` 괄호 안에서 연 것을 끝날 때 자동으로 닫습니다. | `try (Stream<Path> s = Files.list(root))` | `scan/*` |

## 5. 타임리프(Thymeleaf)

| 용어 | 뜻 | 예시 → 결과 | 나오는 파일 |
|---|---|---|---|
| `${…}` | model의 값을 꺼냅니다. 메서드도 부를 수 있습니다. | `${v.book().title}` → `꼬리 살랑, 첫 산책` | 모든 템플릿 |
| `@{…}` | 주소를 만듭니다. `{id}` 자리에 값을 넣고, 서버 모드에서는 폼에 CSRF 칸을 자동으로 넣습니다. | `@{/books/{id}(id=3)}` → `/books/3` | 모든 템플릿 |
| `th:text` | 요소 안의 글자를 계산한 값으로 바꿉니다. `<` `>`는 `&lt;` `&gt;`로 바꿔 넣습니다(태그로 실행되지 않음). | `<b th:text="${title}">제목</b>` → `<b>꼬리 살랑, 첫 산책</b>` | 모든 템플릿 |
| `th:each` | 목록의 항목마다 요소를 하나씩 만듭니다. `name, i :`로 순서(`i.index`)도 받습니다. | `th:each="v : ${books}"` → 카드 5개 | `index.html`, `fragments.html` |
| `th:if` | 조건이 참일 때만 요소를 만듭니다. | `th:if="${error}"` | `index.html` |
| `th:href`, `th:src`, `th:action` | 링크·그림·폼 주소를 `@{…}`로 계산해 넣습니다. | `th:src="@{/download/{id}/cover(id=3)}"` | `book.html`, `index.html` |
| `th:attr`, `th:content` | 아무 속성이나 계산해 넣습니다 / `content` 속성에 넣습니다. | `th:attr="data-id=${c.id}"` → `data-id="13"` | `fragments.html`, `chat.html` |
| `th:classappend` | 조건이 참이면 class 뒤에 덧붙입니다. | `th:classappend="${v.check1()} ? ' ok'"` → `class="check  ok"` | `fragments.html` |
| `th:fragment`, `th:replace` | 다시 쓸 조각을 정의합니다 / 이 요소를 그 조각으로 바꿉니다. 괄호로 값을 넘깁니다. | `th:replace="~{fragments :: head('책 목록')}"` | `fragments.html`, 모든 템플릿 |
| `?:` | 왼쪽 값이 null이면 오른쪽 값을 씁니다. | `${genre} ?: '장르 미정'` | `index.html`, `book.html` |
| `T(클래스)` | 자바 클래스를 가리킵니다. static 메서드·enum을 씁니다. | `${T(com.greendesk.publisher.domain.Stage).values()}` | `fragments.html` |
| `#strings` | 타임리프의 글자 도구입니다. | `#strings.contains(c.text,'[제안]')` | `fragments.html` |
| `${@빈이름.메서드()}` | 스프링 빈의 메서드를 부릅니다. | `${@fmt.ago(m.lastActive)}` → `6시간 전` | `team.html`, `index.html` |
| `${param.이름}` | 주소의 `?이름` 값입니다. | `/login?error` → `${param.error}` 참 | `login.html` |
| `${_csrf}` | 서버 모드에서 CSRF 토큰 정보입니다. | `th:content="${_csrf.token}"` | `chat.html`, `office.html` |
| `sec:authorize` | 로그인 상태에 따라 요소를 만들지 정합니다. | `sec:authorize="isAuthenticated()"` → 로그아웃 단추 | `fragments.html` |
| 타임리프 주석 | 여는 표시 `<!--/*`, 닫는 표시 `*/-->` 사이의 글은 HTML을 만들 때 지워집니다. 이 프로젝트 템플릿의 설명 주석이 이 모양입니다. 보통 HTML 주석 `<!-- -->`은 브라우저까지 갑니다. | 페이지 소스(Ctrl+U)에 보이지 않음 | 모든 템플릿 |

## 6. 자바스크립트

| 용어 | 뜻 | 예시 | 나오는 파일 |
|---|---|---|---|
| 즉시 실행 함수 `(function(){…})()` | 함수를 만들자마자 실행합니다. 안의 변수가 이 파일 안에만 있게 됩니다. | 각 JS 파일 전체 | `static/js/*.js` |
| `'use strict'` | 엄격 모드입니다. 선언하지 않은 변수 사용 같은 실수를 오류로 알려 줍니다. | | `static/js/*.js` |
| `document.getElementById` | id로 요소를 찾습니다. 없으면 `null`입니다. | `document.getElementById('cp')` | `chatpanel.js` |
| `addEventListener` | 사건(이벤트)이 일어나면 함수를 부릅니다. | `form.addEventListener('submit', …)` | `chatpanel.js` |

## 13. GitHub Actions · 서버

| 용어 | 뜻 | 예시 | 나오는 파일 |
|---|---|---|---|
| workflow · `on` · `jobs` · `steps` | 자동 실행 설정 파일 / 언제 / 할 일 묶음 / 차례로 할 단계. | `on: push: branches: [main]` | `.github/workflows/*.yml` |
